# Green Chat

Тестовое задание: чат для отправки и получения сообщений в Telegram через [GREEN-API](https://green-api.com/telegram).

Стек: React, TypeScript, Vite.

## Запуск

Node.js 20.19+ или 22

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

## Как пользоваться

1. Создать инстанс Telegram в [личном кабинете GREEN-API](https://console.green-api.com) и авторизовать его
2. В настройках инстанса включить получение входящих сообщений, Webhook URL оставить пустым
3. Ввести `idInstance` и `apiTokenInstance` на странице входа (`apiUrl` подставится сам)
4. Нажать «+» и ввести номер телефона собеседника

## Что сделано

- отправка сообщений (`SendMessage`)
- получение сообщений через `ReceiveNotification` / `DeleteNotification`
- статусы сообщений (отправлено, доставлено, прочитано)
- история чатов сохраняется в localStorage
- мобильная версия

## Примечания

В Telegram chatId это не номер телефона, а id пользователя, поэтому при создании чата номер сначала проверяется через `CheckAccount`. Если у собеседника в настройках приватности запрещён поиск по номеру, чат создать не получится.

Поддерживаются только текстовые сообщения.
